Custom code here is JavaScript layered on top of Webflow's standard build — almost entirely GSAP-driven scroll and interaction animation (sliders, pinned sections, split-text reveals, a draggable "tornado" card stack, etc.), plus one smooth-scroll library.

<Warning>
  **Current state as of this handoff:** the project's custom-code files live in this repo but are **not yet wired into Webflow** — no scripts are currently registered or applied at the site or page level. The only custom code already live on the site is the Lenis smooth-scroll snippet described below. See [Hosting the Custom Code](/custom-code/hosting) to wire them in.
</Warning>

## The four project files

| File | Scope | What it drives |
|---|---|---|
| [`global.js`](https://github.com/tamyankevich/EP-rework/blob/main/global.js) | **Site-wide** | Nav menu open/close animation and content stagger; hides the nav bar once the footer scrolls into view. Runs on every page. |
| [`home.js`](https://github.com/tamyankevich/EP-rework/blob/main/home.js) | **Home** page only | Cascading image slider, 3D draggable card "tornado" (uses GSAP Observer), sticky steps indicator, hero video object-position handling, a hover sound effect (currently commented out/disabled in the code). |
| [`about.js`](https://github.com/tamyankevich/EP-rework/blob/main/about.js) | **About** page only | Pinning the visuals column against the timeline on mobile, the scroll-driven step-by-step timeline, and the interactive image collage hover/focus effect. |
| [`how-we-work.js`](https://github.com/tamyankevich/EP-rework/blob/main/how-we-work.js) | **Destinations** + **The Collective** pages | Despite the filename (a holdover from an earlier page structure), this file now drives: the sticky-video scroll-reveal service cards on Destinations, and the spatial member-card slider + bio "read more" toggle on The Collective. A third feature that used to live here — a radial cards slider — was removed from the live site and has been cleaned out of the code. |

<Warning>
  **Do not delete or edit custom code unless you are explicitly instructed to.** These files are tightly coupled to specific class names and data attributes in the Webflow structure — small changes on either side (Webflow structure or the JS) can silently break animations.
</Warning>

## Dependencies (load order matters)

These files depend on **GSAP** and several of its plugins, loaded *before* the project files:

- Core: `gsap`
- Plugins used somewhere across the four files: `ScrollTrigger`, `SplitText`, `CustomEase`, `Draggable`, `InertiaPlugin`, `Observer`

<Info>
  GSAP's previously-paid "Club GreenSock" plugins (SplitText, Draggable, InertiaPlugin, Observer, CustomEase) became free for everyone following Webflow's 2025 acquisition of GreenSock — confirm current licensing/CDN links at [gsap.com](https://gsap.com) before wiring these in, but no paid key should be required today.
</Info>

Already live and unrelated to this repo: a **Lenis** smooth-scroll script is loaded site-wide via Project Settings → Custom Code → Footer Code, pulled directly from a public CDN. Leave this as-is unless you're deliberately replacing it.
